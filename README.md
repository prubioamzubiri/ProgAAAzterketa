# ProgAAAzterketa

1. ariketa — Erregresioa (4 puntu)
Lortu zerbitzari-gelen hileko energia-kontsumoa (kontsumoa_kWh) aurreikusteko eredurik onena, energia.csv fitxategiko datuak erabiliz.
Amaitu proba-multzoko emaitzarekin (R²) eta ereduen konparaketa-taula batekin (eredua, hiperparametro onenak, CV puntuazioa).
2. ariketa — Sailkapena (6 puntu)
Lortu ekipo industrialen hurrengo hilabeteko hutsegitea (hutsegitea: 1 = huts egingo du) aurreikusteko eredurik onena, hutsegiteak.csv fitxategiko datuak erabiliz.
Hutsegite bat detektatu gabe uzteak geldialdi garestia dakar; alarma faltsu batek, berriz, teknikari baten bisita alferrikakoa bakarrik. Mantentze-taldeak hutsegite guztien gutxienez %85 detektatu nahi du eta, hori beteta, alarma faltsu ahalik eta gutxien.
